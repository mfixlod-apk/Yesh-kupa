# יש קופה (Yesh Kupa)

אפליקציית Android Native לניהול קופה ומלאי, בממשק עברי RTL.

## יכולות שנכללו בקוד הנוכחי

- מסכים נפרדים: קופה, מלאי, דוחות והגדרות.
- קטלוג מוצרים מקומי ב-SQLite.
- פרטי מוצר: שם, ברקוד, קטגוריה, עלות, מחיר מכירה וכמות במלאי.
- חיפוש לפי שם, ברקוד או קטגוריה; ניתן להזין ברקוד ידנית בשדה הקופה.
- סל קנייה עם שינוי כמויות ובדיקת זמינות מלאי.
- שמירת מכירה, הפחתת מלאי ושמירת עלות המוצר בעת המכירה.
- דוחות מחזור יומי וחודשי, שווי מלאי לפי עלות ורווח גולמי משוער.
- איתור התקני USB Host ובקשת הרשאה דרך Android.
- הצגת התקני Bluetooth קלאסיים שכבר הותאמו למכשיר וחיבור באמצעות SPP.
- הדפסת קבלה גרפית ב-ESC/POS, כולל ציור טקסט עברי RTL כתמונת מדפסת ברוחב 80 מ"מ (576 נקודות).
- אפשרות להדפיס קבלה אחרונה והגדרת הדפסה אוטומטית לאחר מכירה.

## מגבלות ידועות שצריך לבדוק

- זיהוי USB מציג התקני USB; לא כל התקן שמופיע הוא מדפסת. נדרשת תמיכת USB Bulk OUT.
- Bluetooth מאתר התקנים שכבר הותאמו (Paired) ותומכים בפרופיל Serial Port (SPP); BLE בלבד אינו נתמך במנגנון הזה.
- רוחב ההדפסה מוגדר כרגע ל-80 מ"מ / 576 נקודות. יש להתאים למדפסות 58 מ"מ.
- לא בוצעה עדיין בדיקת חומרה בפועל מול דגמי המדפסות של המשתמש. הצלחת קומפילציה אינה אישור לתאימות פיזית.
- סריקת ברקוד באמצעות מצלמה, ניהול ספקים/רכש, גיבוי ענן, סנכרון בין מכשירים, משתמשים והרשאות מתקדמות עדיין לא קיימים.
- הרווח בדוח הוא רווח גולמי לפי עלות המוצר שנשמרה במועד המכירה. הוא אינו כולל מע"מ, הוצאות עסק, עמלות או החזרות.

## בניית APK

כל push לענף `main` מפעיל GitHub Actions. לאחר ריצה מוצלחת, יש להוריד את `yesh-kupa-debug-apk` מאזור Artifacts של אותה ריצה ולחלץ את קובץ ה-ZIP כדי להתקין את קובץ ה-APK.

## הבהרה חשובה

זו גרסת פיתוח ובדיקות. הנתונים נשמרים מקומית במכשיר. האפליקציה אינה מערכת חשבונאית מאושרת ואינה תחליף לתוכנת חשבוניות מאושרת. אין להשתמש בה להפקת מסמכים חשבונאיים או קבלות מס. לפני שימוש מסחרי נדרשים בדיקות, גיבוי, אבטחה ובדיקת דרישות הדין בישראל מול גורם מקצועי.
