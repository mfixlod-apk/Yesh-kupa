# יש קופה (Yesh Kupa)

אפליקציית Android לניהול מכירות ומוצרים בעסק קטן, עם ממשק בעברית ובכיווניות RTL.

## מה קיים בגרסת ה-MVP

- אפליקציית Android Native ב-Kotlin.
- קטלוג מוצרים מקומי עם שם ומחיר מכירה.
- חיפוש מוצרים לפי שם.
- סל קנייה עם שינוי כמויות.
- שמירת מכירות ופריטי מכירה במסד SQLite מקומי.
- סיכום מחזור מכירות יומי.
- איתור התקני USB המחוברים למכשיר ובקשת הרשאת גישה.
- הצגת התקני Bluetooth שכבר הותאמו למכשיר וחיבור למדפסות קלאסיות התומכות SPP.
- שליחת דף ניסיון בסיסי בפורמט ESC/POS דרך USB או Bluetooth.
- תהליך CI ב-GitHub Actions לבניית APK.

## מה עדיין לא קיים

סריקת ברקוד, ניהול מלאי ועלויות, חישוב רווח, גיבוי ענן, משתמשים והרשאות וסנכרון בין מכשירים — נמצאים בתוכנית ההמשך. ההדפסה הנוכחית היא בדיקת ESC/POS בסיסית בלבד: אין עדיין עיצוב קבלה בעברית, בחירת רוחב נייר, חיתוך מותאם לדגם או בדיקת תאימות לכל מדפסת. Bluetooth מאתר התקנים מותאמים בלבד; USB עשוי להציג גם התקנים שאינם מדפסות.

## בניית APK

כל push לענף `main` מפעיל את תהליך Android APK Build. לאחר ריצה מוצלחת, ניתן להוריד את `yesh-kupa-debug-apk` מאזור Artifacts של אותה ריצה.

## הבהרה חשובה

זו גרסת MVP לפיתוח ולבדיקות בלבד. הנתונים נשמרים מקומית במכשיר. האפליקציה אינה מערכת חשבונאית מאושרת ואינה תחליף לתוכנת חשבוניות מאושרת. אין להשתמש בה להפקת מסמכים חשבונאיים. לפני שימוש מסחרי נדרשים בדיקות, גיבוי, אבטחה ובדיקת דרישות הדין בישראל מול גורם מקצועי.
